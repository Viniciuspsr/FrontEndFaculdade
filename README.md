# FrontEndFaculdade

## Apresentação do projeto
Site de uma ONG desenvolvido como projeto acadêmico, com páginas para apresentar projetos e permitir o cadastro de informações.

## Tecnologias utilizadas
- **HTML5:** estrutura e semântica das páginas.
- **CSS3:** estilização, responsividade, Flexbox e CSS Grid.
- **JavaScript:** interações, navegação SPA e alternância entre temas claro e escuro.

## Estrutura do projeto
- `html/`: páginas HTML.
- `css/`: folhas de estilo.
- `imagens/`: recursos visuais.
- `js/`: scripts JavaScript.

## Requisitos
- Git.
- Visual Studio Code.
- Navegador atualizado.
- Extensão Live Server no VS Code.

## Instalação e execução
1. Clone o repositório:
   `git clone git@github.com:Viniciuspsr/FrontEndFaculdade.git`
2. Abra a pasta do projeto no Visual Studio Code.
3. Utilize a extensão Live Server para abrir `html/index.html` no navegador.

O projeto utiliza HTML, CSS e JavaScript sem ferramentas de build ou dependências adicionais configuradas.

## Versionamento e colaboração
O projeto utiliza Git e GitHub, com branches `main`, `develop`, `feature/` e `hotfix/`. As alterações são registradas por commits, tags de versionamento semântico, Issues, Milestones e Pull Requests.
